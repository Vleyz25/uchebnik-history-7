# Офлайн-шпаргалка по учебнику

Генератор создаёт HTML-страницу с офлайн-поиском по текстовому PDF: результаты содержат фрагменты исходного учебника и номера страниц. После создания HTML интернет не нужен.

## Создать шпаргалку из своего PDF

Нужен Python 3.10 или новее. PDF должен содержать извлекаемый текст; PDF-сканы без текстового слоя не распознаются.

```bash
python -m pip install -r requirements.txt
python make_cheatsheet.py "путь/к/учебнику.pdf"
```

HTML появится рядом с PDF с тем же именем и расширением `.html`. Можно задать другое расположение:

```bash
python make_cheatsheet.py "путь/к/учебнику.pdf" --output "моя-шпаргалка.html"
```

Откройте полученный HTML в браузере. PDF и интернет для дальнейшего поиска не нужны: текст книги встроен в HTML.

## Файлы

- `make_cheatsheet.py` — генератор HTML из произвольного PDF.
- `extract_pdf.py`, `build_app.py` — извлечение текста и сборка поиска.
- `учебник.html` — готовая версия по учебнику истории 7 класса, если она включена в распространяемый пакет.
- `uchebnik.apk` — Android-приложение, если оно включено в распространяемый пакет.

## Важно о распространении

Сгенерированные HTML и APK включают текст учебника. Публикуйте их и исходный PDF только если у вас есть необходимые права или разрешение на распространение. Сам генератор не содержит PDF.

Для некоторых учебников специальные правила обработки страниц в `build_app.py` могут требовать настройки; проверьте охват страниц и результаты поиска на своём PDF.
